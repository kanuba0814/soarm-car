# Single .002 Second Physics-Step Experiment

This is one private Intel-only resource experiment, not a new baseline. The matched corrected house launch SHA-256 remains `a520fa54f04feb26b2ceb8da8723046b89c2c8ab1d4cb1444cba63df17ec94d5`. `world-step-overlay.diff` proves the only world change is physical `max_step_size` from `0.001` to `0.002` seconds. Sensor FOV, range, rates, geometry, control rate, IMU rate, LiDAR rate, Nav2, health policy, command gate, and source timestamps were unchanged. The original world furniture include was explicitly restored before the run.

The isolated environment is exactly `run-step-002.sh`: `ROS_DOMAIN_ID=99`, `ROS_LOCALHOST_ONLY=1`, `IGN_PARTITION=soarm-step-002-99`, `IGN_IP=127.0.0.1`, private IPC, `--network none`, `--shm-size 256m`, and `/dev/dri/renderD128` only. OGRE confirms Intel Mesa ARL.

The pre-goal observer ran 35.049243901 wall seconds. Sim time advanced 17.598 seconds, with 176 unique raw source frames, 0.1 second maximum source-stamp spacing, median source-clock lag 0.024 seconds, and maximum lag 0.068 seconds. It observed nine raw receipt gaps above 0.5 wall seconds, worst 0.802681962 seconds, and a maximum clock callback wall gap of 0.669256816 seconds. This is still clock/runtime scheduling variability, not a converter source-order problem. Before bootstrap localization is intentionally absent, so pre-goal localization-to-truth error is unavailable. Truth stayed dynamically stable: maximum absolute roll 1.5378326e-06 rad and pitch 3.4467533e-09 rad; no teleport was performed.

The original six zero-origin bootstrap was retained. The minimal overlay recorded in `consumer-handshake-overlay.diff` required two continuous wall seconds of healthy localization and then called the existing `/localization_cmd_gate/arm` Trigger once. It succeeded with `continuous_healthy_wall_s=2.039838551` and `Gate armed; waiting for a fresh navigation command.` No force-clear or rearm occurred.

The unchanged room-1 route body then generated a 109-point 5.850283770 m plan. Its accepted goal was canceled after 0.028 sim seconds / 0.422396331 wall seconds with 0.000280448 m truth progress. The first goal window has no localization sample, so localization-to-truth maximum is unavailable; the run does not establish navigation or post-goal dynamics stability. `route-comparison.json` compares it with the corrected `.001` result, which was also canceled and had no goal-window localization error sample.
