# 产品目标：到指定地点抓取

## 唯一首版任务

机器人接收一个受限任务：

```text
到指定地点抓取指定物体
```

任务输入：

- `place_id`：地图中预先登记的命名抓取地点；
- `object_id`：预先登记的白名单物体类别；
- `request_id`：用于幂等和审计的唯一请求 ID。

首版不接受自由坐标、开放词汇物体或自由文本生成的运动轨迹。

## 成功定义

只有以下步骤全部完成，任务才报告成功：

1. 请求通过身份、白名单、TTL、幂等和当前状态检查；
2. Nav2 将底盘导航到 `place_id` 对应的预抓取位姿；
3. 底盘停稳并保持，定位和传感器数据新鲜；
4. 深度相机在该地点识别 `object_id` 并产生可用的 6D 位姿；
5. 目标位于机械臂工作区，MoveIt 规划和碰撞检查通过；
6. SO-ARM101 执行预抓取、接近、闭合抓手和抬升；
7. 抓取结果通过抓手状态、位姿或视觉复核；
8. 机械臂进入安全持物姿态，底盘仍保持停稳；
9. 系统记录任务结果并向调用方报告成功。

“导航到达”或“抓手闭合”单独发生都不算任务成功。

## 安全失败

任一步骤失败时：

- 取消当前 Nav2 或 MoveIt 动作；
- 停止底盘并禁止新的底盘运动；
- 机械臂进入经过验证的停止、保持或安全撤回状态；
- 不自动重放旧请求，不自动换目标物体；
- 返回结构化失败阶段、原因和可恢复性；
- 实体急停始终可独立切断运动。

首版可以在严格上限内对感知或规划进行有限重试，但不能在位置未知、目标丢失、碰撞场景过期或通信异常时继续动作。

## 任务状态机

```text
IDLE
  -> VALIDATING
  -> NAVIGATING
  -> WAITING_FOR_BASE_STATIONARY
  -> PERCEIVING
  -> PLANNING_GRASP
  -> EXECUTING_GRASP
  -> VERIFYING_GRASP
  -> HOLDING_OBJECT
  -> SUCCEEDED
```

任何运行状态都可以进入：

```text
STOPPING -> FAILED
CANCELLING -> CANCELLED
```

## 首版范围

包含：

- 一个受控场景；
- 少量命名抓取地点；
- 一种白名单物体；
- 固定或受限桌面高度；
- 底盘停稳后抓取；
- 本地离线语音、Agent 或操作界面触发同一个 MHS task；
- 全链路取消、停止、超时、审计和结构化错误。

不包含：

- 移动中抓取；
- 任意地点或任意物体；
- 抓取后返回、配送或放置到第二地点；
- 云端参与实时运动闭环；
- 自动解除急停或安全互锁；
- 由 LLM 直接生成底盘速度或关节轨迹。

## 产品验收

在受控场景连续执行至少 20 次完整任务，记录：

- 完整任务成功率；
- 导航到位误差；
- 从到位到停稳的时间；
- 物体识别和位姿成功率；
- 规划、抓取和抓取验证成功率；
- 总任务时间；
- 每种失败原因；
- CPU、内存、温度、USB 和供电状态。

此外必须通过停止、取消、目标消失、目标不可达、相机数据过期、底盘反馈丢失、机械臂通信丢失、MHS Host 崩溃和急停等负面测试。
