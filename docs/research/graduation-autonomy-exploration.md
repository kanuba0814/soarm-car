# 毕业设计：低人工干预任务扩展探索

## 范围与证据口径

本轮研究以当前工作区为准，基线提交为 `41463f9a07dc317eb837558ad55b137fb92e35eb`，但工作区包含尚未提交的房间导航、感知和定位安全成果，不能把 HEAD 单独当成受测版本。探索不替换现有产品范围，不把候选方案描述为已经实现的功能。

目标是：**在不削弱安全约束的前提下，以少量可验证技能组合更多任务，降低每个成功任务的人工操作量。** 当前默认模型未安装机械臂；抓取、配送和物理机器人可靠性均不能由此次研究证明。

## 本轮直接验证

父会话在主工作区运行：

```bash
PYTHONDONTWRITEBYTECODE=1 \
PYTHONPATH=ros2_ws/src/soarm_room_navigation:ros2_ws/src/soarm_room_search \
python3 -m pytest -q -p no:cacheprovider \
  ros2_ws/src/soarm_room_navigation/test \
  ros2_ws/src/soarm_room_search/test/test_core.py
```

结果：**38 passed, 2 subtests passed，3.33 秒**。这是现有软件逻辑测试，不是实际语言理解、全屋导航覆盖或真机试验。

测试收集确认覆盖以下边界（测试名称可在相应源文件检索）：

- 顺序访问、等待、返回起点、每步至多一次 fallback；
- 运动成功后等待零输出，不把 action success 直接当成底盘停稳；
- 超时先取消并等待真实终态，迟到回调与未决取消不能触发新运动；
- 停止/安全丢失抢占 fallback，损坏日志 fail-closed，重启不自动重放；
- 单一模型请求、严格 JSON、房间版本冲突、同源 HTTP；
- 自动安全房间目标、位置到达语义、地图/点云坐标与新鲜度；
- 找桌模块的合成点云、扫描覆盖和路径失败闭锁。

上述最后一项使用合成数据，不证明真实桌面识别准确率。

## 适合论文的评价方式

建议题目方向：**面向室内移动机器人的受限任务编排与低干预自主执行研究**。

避免以“支持多少条自然语言句子”作为任务能力指标。以独立任务类别、环境变化与失败恢复能力为评价单位。

| 指标 | 建议定义 | 防止误导 |
|---|---|---|
| 任务成功率 | 满足预先定义的终态 / 全部试次 | 报告失败与超时，不删失败样本 |
| 无额外干预完成率 | 首次授权后无人工介入且成功 / 全部试次 | 首次授权与恢复干预分别记录 |
| 人工操作负担 | 初始配置、逐任务确认、异常恢复分别计次/计时 | 不能只统计成功任务 |
| 任务覆盖 | 在固定技能集合上验证的不同任务类别数 | 同义改写不算新类别 |
| 恢复表现 | 可恢复故障的完成率、额外耗时与重试次数 | 安全故障不得通过自动重启掩盖 |
| 事实可信度 | 有可追溯传感器/动作证据的结果比例 | 模型自述、fixture输出不算事实 |
| 资源与隔离 | CPU/内存/耗时、遗留进程、跨实验通信 | 比较方法使用同等资源上限 |

对比组可设为：逐步人工下发、单任务确定性执行、一次确认的组合任务；语言理解另设规则基线与真实模型对比。各组应使用相同地图、起点、目标、超时和失败定义，记录重复试验分布，不用单次演示声称可靠性提升。

## 进程与验证约定

1. 每条写入线一个独立 worktree。未提交文件不会自动出现在 worktree；测试前显式确定源码快照，不误测旧 HEAD。
2. ROS/仿真启动权唯一；确需并行才拆分独立容器网络、`ROS_DOMAIN_ID`、`IGN_PARTITION`、服务端口和输出目录。工作树隔离不能代替运行时隔离。
3. 每次验证使用新容器/新进程，不沿用上次状态；明确有限超时和退出清理。
4. 容器使用本轮唯一名称前缀，只清理自身资源。不使用 `pkill`、`killall`、`docker prune`，不停止已有服务。
5. 不接真实电机、相机设备或未经授权的远端模型；不把凭证、原始私密视频发往外部服务。
6. 限制同机重型构建/仿真并发；运行前检查磁盘与内存。启动时本机无运行容器，磁盘仅约 70 GB 可用，不宜随意复制数据集或重建大镜像。
7. 降低人工干预不等于取消安全确认。停止后的显式重使能、未决取消、地图变更和重启后的禁止自动重放边界应保留。

## 最终探索清单

| 方向 | 结论 | 优先级 |
|---|---|---|
| 单/多房间访问、等待、返回起点 | 已有受限编排基础；优先开展重复仿真，不以单元测试替代实际到达 | P0 |
| 预授权普通失败备选 | 已有每步一次备选，安全异常不能自动恢复 | P0 |
| 巡检观察 | 复用导航与扫描，仍需统一执行所有权并新增观测证据终态 | P1 |
| 离线找物与最后位置查询 | 先返回候选和支持帧，不把历史记录说成当前位置 | P1 |
| 清点草案 | 先解决物理实例去重、命名与人工冻结评分规则，不继续堆模型 | P1 |
| 变化复查 | 需要跨次关联，区分遮挡、未见与真正消失 | P2 |
| 抓取与配送 | 未装机械臂，无已验证闭环，不列为当前必达项 | 暂缓 |

推荐毕业设计主线：**一次授权的组合导航 + 有证据的巡检/找物**。搜索与导航目前不是可直接拼接的共同执行器：地图身份、底盘净空、房间版本和运动目标所有权需要统一。降低重复确认不等于移除安全门禁。
