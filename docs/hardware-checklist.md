# 硬件确认清单

本清单服务于唯一任务：机器人到命名地点停稳后抓取白名单物体。除设备本身外，必须测量抓取地点、物体和底盘到机械臂工作区的几何关系。

## 首版场景与物体

- [ ] 确定一个命名抓取地点 `place_id`，测量导航预抓取位姿和允许误差。
- [ ] 测量桌面/承载面高度、边缘、周围障碍和可供底盘停靠的空间。
- [ ] 确定一个白名单物体 `object_id`，记录尺寸、质量、材质和可抓区域。
- [ ] 验证底盘到位误差下，目标仍同时处于相机视野和机械臂可达工作区。
- [ ] 确定持物验证方法：抓手位置/负载、物体视觉复核或两者组合。
- [ ] 定义抓取成功后的安全持物姿态；首版不要求配送或放置。

## 底盘

- [ ] 拍摄底盘铭牌、STM32 控制板正反面、显示屏上电信息和所有接口。
- [ ] 确认车型配置：`mini_4wd`、`four_wheel_diff` 或其他；图片本身不能证明运动学。
- [ ] 测量轮距、轴距、轮径、上板尺寸/厚度/孔距和离地高度。
- [ ] 记录电池化学体系、标称/满充电压、容量、BMS 持续/峰值电流。
- [ ] 查询整车额定载荷；称量当前整车。
- [ ] 确认电机使能和总电源断开方式。

## 树莓派 5

- [ ] RAM 容量、存储介质、主动散热、5V 电源额定值。
- [ ] USB 设备拓扑；底盘串口和麦克风放 USB2，高带宽相机放 USB3。
- [ ] 不从 GPIO/普通 USB 给机械臂舵机供电。

## SO-ARM101 follower

- [ ] 控制板准确型号、输入电压/极性和电源额定电流。
- [ ] 6 个 STS3215 的 ID、baudrate、固件/配置和校准文件。
- [ ] 臂、夹爪、控制板、支架和线束总质量。
- [ ] 最大工作半径、允许负载和关节软/硬限位。
- [ ] 臂底座布置在轮廓中心附近并尽量低；加强板不只依赖薄上盖。
- [ ] 最大伸展 + 最大负载时，投影重心仍在支撑多边形内并留动态裕度。
- [ ] 关节线缆有应力释放，不经过轮胎、散热器或夹爪工作区。

## 奥比中光深度相机（优先）

- [ ] 铭牌型号、序列号、USB VID:PID（Orbbec 常见 VID `2bc5`）。
- [ ] 是老 OpenNI 设备还是 OrbbecSDK v2 设备。
- [ ] USB2/USB3、供电需求、RGB 与 depth 支持的分辨率/帧率。
- [ ] 相机固定后完成内参检查与 `base_link -> camera_link` 外参。
- [ ] 抓取相机视野覆盖机械臂工作区，且臂不会长期遮挡目标。

## Livox MID-360

- [x] 型号确定为 Livox MID-360；定位依赖官方 `livox_ros_driver2/msg_MID360_launch.py`。
- [ ] 记录序列号、固件、输入电压、典型/峰值功耗和以太网接口。
- [ ] 记录雷达 IP、主机网卡 IP、子网和 `MID360_config.json`；确认无地址冲突。
- [ ] 验证 `/livox/lidar` 为 `livox_ros_driver2/msg/CustomMsg`，`/livox/imu` 为 `sensor_msgs/msg/Imu`。
- [ ] 核实 LiDAR/IMU 时间同步、时间偏移和掉线重连行为。
- [ ] 测量并标定 `base_link -> livox_frame` 6D 外参；收到配置中的示例外参不能直接使用。
- [ ] 获取/生成真实 PCD 地图，并记录地图坐标原点、版本和适用场地。
- [ ] 安装高度兼顾无遮挡和整车重心；机械臂全行程不撞雷达。

## 麦克风/语音

- [ ] 是否为 WHEELTEC 当前标配 M2 讯飞阵列；保存 USB VID:PID 和 `/dev/wheeltec_mic` 规则。
- [ ] 离线 SDK、appid、模型语言、授权方式和许可证。
- [ ] 电机/风扇运行时录音信噪比。

## 电源树

先实测再填写：

| 负载 | 电压 | 连续电流 | 峰值电流 | 支路保护 |
|---|---:|---:|---:|---|
| 底盘电机/STM32 | 待测 | 待测 | 待测 | 原 BMS + 保险 |
| 树莓派 5 | 5 V | 待测 | 待测 | 独立 DC/DC + 保险 |
| SO-ARM101 | 待控制板确认 | 待测 | 待测 | 独立支路 + 急停 |
| 深度相机 | 待型号确认 | 待测 | 待测 | USB 供电预算 |
| 3D 雷达 | 待型号确认 | 待测 | 待测 | 独立保险 |
| 麦克风 | 5 V/待确认 | 待测 | 待测 | USB 供电预算 |

电源设计的验收不是“能开机”，而是底盘急加速和机械臂多关节同时动作时 Pi 不欠压、USB 不重连、STM32 不复位。
