## 1. A1：RGB-D 行对应验证——顶部裁剪假设成立

**问题**：此前"RGB 顶部 400 行对应 640×400 深度"仅依据相同 K、驱动点云分支和目视叠加；`rgb_depth_registration.verified=false`。

**方法**：对每个配对帧抽取深度不连续像素（相邻有效深度差 >0.05 m），在仿射行映射 `rgb_row = a·depth_row + b` 下统计这些像素落在强 RGB 梯度（所在窗口 Sobel 幅值前 25%）的比例；a∈{1.0,1.05,…,1.25} 覆盖"纯裁剪"与"不同垂直 FOV"两类假设，b 全程扫描；行循环移位置换给出噪声底。再用联合前端在 b=0、b=1、b=40（中心裁剪对照）上跑完整序列做独立确认。逐帧归一化（窗口内前 25% 梯度为"强"）保证不同纹理帧可比。

**结果**（`data-acceptance-20260916/<bag>/a1/`）：

| 指标 | 212016 | 212121 |
|---|---|---|
| 参与帧数（≥150 边缘像素） | 393/638 | 354/370 |
| 最优映射 | a=1.00, b=1（0.4695） | a=1.00, b=0（0.5238） |
| b=0 得分 / 噪声底 p95 | 0.4672 / 0.4467 | 0.5238 / 0.4354 |
| 前八名中的非纯裁剪 (a≠1) 映射 | 0 个 | 0 个 |
| 水平扫描最优 dx | −1（dx=0 为 0.489） | +2（dx=0 为 0.527） |

- 两段的最优解都在 b=0–1，且得分随 b 增大单调下降；b=0 与 b=1 的 bootstrap 置信区间重叠（第一段），第二段 b=0 明确最优。**所有缩放假设（a≠1，含"同 FOV 等比 a=1.2"）全部排在纯裁剪之后。**
- 水平方向最优 dx 在 ±2 px 内波动，无系统性水平错位。
- 里程计确认（完整序列，同冻结参数）：b=0 通过率 98.35%/97.56%（与冻结轮一致，作复算 sanity），b=1 为 98.27%，b=40 中心裁剪 97.80%/97.56%；深度一致率 b=0 0.9448/0.9187，b=40 0.9435/0.9168。**b=0 与 b=1 在里程计指标上不可区分，中心裁剪略差。**

**结论**：顶部裁剪（b=0，容许 ±1 px）假设得到两类独立证据支持，无需修改标定输入。**该验证只确认行映射关系，不确认 K 本身的绝对精度**——标定板录制仍是下一轮清单项（见 §7）。

## 2. A3：深度有效区、边缘与噪声——可测部分

全部统计在 `data-acceptance-20260916/<bag>/a3/`。阈值（0.3–5 m 有效、0.05 m 边缘判据、0.3 m 跳变混合判据）是本轮显式分析选择，非传感器规格。

| 指标 | 212016 | 212121 |
|---|---|---|
| 每帧有效像素比例（中位） | 0.887 | 0.841 |
| 有效比例按行带（上/中/下） | 0.876 / 0.980 / 0.863 | 0.759 / 0.887 / 0.860 |
| 深度分布 p25–p75 (m) | 1.56–2.29 | 1.11–1.58 |
| 无效连通域面积（中位 / p90 / 最大, px） | 32 / 768 / 77432 | 76 / 1228 / 104496 |
| >0.3 m 跳变处过渡像素：中位 / p90 / ≥2px 比例 | 0 / 0 / 0.03% | 0 / 0 / 0% |
| 近静止对数量（帧间步长 <5 mm、<0.2°） | 54 | 20 |
| 闪烁中位 |Δd|：1–1.5 m / 1.5–2 m / 2–2.5 m / 2.5–3 m | 7 / 8 / 18 / 24 mm | 7 / 11 / 14 mm / — |

孔洞统计为每帧最多取前 50 大连通域（避免整片无效区淹没分布）；最大孔洞（>7.7 万 / >10 万像素）出现在整片无效的区域（如窗户/屏幕方向），逐帧分布见 JSON。

- **边缘混合极小**：在 0.3 m 跳变判据下，深度过渡宽度中位与 p90 均为 0 px，≥2 px 比例 ≤0.03%。按此判据该传感器没有明显的"飞行像素带宽"问题；更细的亚像素混合需要亚像素级分析，本轮未做。
- **噪声随距离增长**：近静止对上同像素深度变化中位从 1–1.5 m 的约 7 mm 增至 2.5–3 m 的约 24 mm。近静止段由冻结联合前端判定（步长 <5 mm/<0.2°），若场景内有未致帧间拒绝的真实运动，该数字是其上界。
- **限制**：无已知距离真值，本组不产出深度偏差结论；>3 m 无近静止样本；孔洞集中在上/下行带与玻璃/屏幕方向，与办公室场景结构一致，不能当作传感器缺陷单独归因。

## 3. A2：时间戳语义与配对偏移扫描

两段 bag 的 header stamp 均单调；header 与 rosbag 接收时间的差值如下。该差值只能刻画驱动到写包的相对时延，不能单独证明 header 是曝光起点、曝光中点或设备到达时刻。

| bag | depth recv−header 中位 | RGB recv−header 中位 | depth/RGB 帧间隔中位 | RGB 最大帧间隔 |
|---|---:|---:|---:|---:|
| `212016` | 0.41 ms | 11.84 ms | 34.8 / 35.9 ms | 84.4 ms |
| `212121` | 0.38 ms | 11.96 ms | 34.8 / 40.0 ms | 84.2 ms |

以 RGB 时间为基准，将深度在 −24 至 +24 ms 间重配对，并在各偏移共同拥有的 1002/668 条边上重跑冻结联合前端。`212016` 的接受率为 98.5%–99.4%、深度一致率为 94.13%–94.36%；`212121` 分别为 97.46%–98.65%、91.38%–91.98%。曲线没有单一、跨序列一致的最优偏移，0 ms 与邻近偏移的差异也小于场景波动，因此**现有数据不支持引入固定补偿，保留最近时间戳配对**。

观察到的运动在两段中的 p90 为 0.85/0.77 m/s 与 54.0/64.1°/s。按此速度给出的 8 ms 未建模偏移上界为 0.68/0.61 cm、0.43/0.51°（16 ms 约翻倍）。这说明高速转动时十毫秒级偏移不可忽略，但现有非受控轨迹无法辨识其符号和曝光语义；下一轮需按 §7 的受控单轴实验补齐。

## 6. C3：确定性深度来源消融

四臂为原始深度、全局 5×5 中值、最近有效像素仅填洞、远离深度边缘才中值化。留出实验移除完整 5×5 有效块：仅填洞覆盖 100%；中值只能从块边界恢复约 42%–47% 像素；边缘门控按定义不改无效像素，覆盖为 0。误差只在实际产生预测的像素上统计，未预测像素不再误记为米级误差。

在 1–2 m，最近邻填洞的块内 p90 中位为 5–12 mm，含任一 >10 cm 误差像素的块占 0%–1.7%。在 TUM desk 的 3.5–5 m，该 p90 增至 37–38 mm，且 0%–0.9% 的块出现 >10 cm 像素；模拟留出仅代表已测表面，不能代表玻璃、遮挡边界或真实未知孔洞。

| 数据 / 指标 | 原始 | 5×5 中值 | 仅填洞 | 边缘门控 |
|---|---:|---:|---:|---:|
| fr1/desk ATE RMSE | 3.02 cm | **1.92 cm** | 2.19 cm | 3.08 cm |
| fr1/desk 错误接受率 | 1.65% | 1.10% | **0.55%** | 1.47% |
| fr1/room ATE RMSE | 19.63 cm | 19.80 cm | 23.54 cm | **19.51 cm** |
| 冻结 fr3/long ATE RMSE | **47.44 cm** | 49.88 cm | 71.63 cm | 47.89 cm |
| 冻结 fr3/long 1 s 平移 RPE 中位 | **2.01 cm** | 2.12 cm | 3.13 cm | 2.06 cm |

DC1 两段无 GT；仅填洞把接受率从 98.35%/97.56% 提高到 99.69%/99.73%，但增加约 1.1 ms 双向处理时间，且冻结真值序列的 ATE 恶化 51%。开发集的局部收益没有在冻结长序列复现。**结论：默认保留原始深度；不启用无置信度填洞或全局中值。边缘门控接近无害但无稳定收益，也不进入默认路径。** 模型补全和置信度校准臂因无 CUDA GPU/校准数据未运行。
